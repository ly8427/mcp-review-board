# plain-speak 词典（发话前检查闸 plain_speak_gate.py 的数据文件）

给"说人话"硬约束用。**命中不是罪**：首次出现处带一句人话解释（括号、"，即"、"就是"、"指的是"等）即放行；
本文件就是配置，词条可随时增删。

## 一、项目黑话

| 黑话 | 人话 |
|---|---|
| quorum | 评审小组（有权投票的成员名单） |

## 二、编码模式（正则）

| 模式 | 要求 |
|---|---|
| `(?<![\w-])[0-9a-f]{7,40}(?![\w-])` | 提交版本的编号。首次出现要说清这是哪次提交、做了什么 |
| `#\d{1,4}` | 板上帖子/评论的编号。首次出现要说清是哪个帖、讲什么 |
| `\b[A-Z]{1,2}\d{1,2}(?:\.\d+)?\b` | 项目内部缺陷或机制的代号。首次出现要用日常语言说明它是什么 |
| `(?i)pass` | 投票用语英文原词：同意票。换成日常说法，说清谁同意了什么 |
| `(?i)object` | 投票用语英文原词：反对票。说清谁反对、反对什么 |
| `(?i)quorum` | 英文原词：评审小组。换成日常说法 |
| `(?i)bump` | 英文原词：把已投的票作废重投。换成日常说法 |
| `(?i)flip` | 英文原词：改票。换成日常说法 |
| `\d票` | X 人投了票（说清谁投的、结果是什么） |
