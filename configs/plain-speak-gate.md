# plain-speak gate：发话前的"说人话"检查闸（Stop hook）

## 它防什么

用户要求（2026-10-21/22 确立为硬要求）：agent 向用户的汇报禁止黑话裸奔。写在指令文件里的
文字规矩只能降频不能封死（本项目已三次验证此结论：发起者义务→quorum-guard、成本浪费→
automation-guard、说人话→本闸）。

## 机制

宿主在 agent **结束每次回复**时（Stop 事件）自动调用 `plain_speak_gate.py`：取出刚写完的
回复全文 → 剔除代码块和链接 → 对照词典扫描 → 发现"没带解释的黑话"→ 把回复打回重写
（每轮最多打回一次，宿主另有三次上限）；干净、已解释、或读不到文本 → 放行。

**豁免原则（继承社区词典的哲学）**：命中不是罪。词条首次出现处 40 字内跟着括号、
"，即"、"就是"、"指的是"等解释标记 → 放行。项目里真有名字的东西（如某规则的编号）不是
禁词，但首次出现必须带一句人话解释——这正是豁免标记的用途。

词典 = `plain-speak-dictionary.md`（本目录，人可直接编辑，就是配置）：
- 一、项目黑话（投票/看板/工程专用词 + 人话换法）
- 二、编码模式（正则：提交号、帖子编号、内部代号、英文投票词、N 票）
- 三、白名单（永不标记的日常用语——调误拦的第一入口）
- 四、进口通用词典 633 条（见致谢）

## 安装（每个宿主一次）

`~/.zcode/cli/config.json` 顶层 `hooks.events` 里加 Stop 条目（与其他 hook 并存）：

```json
"Stop": [
  {
    "hooks": [{
      "type": "command",
      "command": "\"<python>\" \"<repo>/configs/plain_speak_gate.py\"",
      "timeoutMs": 10000,
      "statusMessage": "plain-speak 发话前检查"
    }]
  }
]
```

改完需重启客户端/新会话生效。卸载 = 删掉这个 Stop 条目。

## 影响面与失败哲学

- 生效范围：本宿主**所有会话**的每一条最终回复（不分工作区）。
- 失败哲学：**fail-open**——脚本任何内部错误、读不到回复文本 → 一律放行，绝不拦死正常
  说话；最坏失效模式是"检查静默失效"，不是"乱拦"。
- 防循环：宿主标记"本轮已打回过"后本闸不再拦；误拦的止损口 = 把词加进词典白名单。
- 已知边界：回复文本取自 Stop 事件的载荷（不足时退读会话日志尾段），格式随宿主版本
  可能漂移——漂移即 fail-open；英文投票词、提交号等编码模式对英文报告同样生效。

## 验证状态（如实）

脚本级 10 用例全绿（旧文风打回/解释版放行/干净放行/防循环/垃圾输入/代码块剔除/英文投票词
打回/三票打回/人话放行/守卫误拦修正）。**实弹未打**：真实会话里被打回重写一例尚未发生
（需重启客户端后的下一个会话验证）；Stop 载荷格式按防御式解析写成，首个真实触发即为验收点。
